## 2. コアループ

> 「操作 → 結果 → 報酬 → 次の操作」のサイクル。

- **操作**: プレイヤーは端末の傾き（加速度センサ）または横スワイプで、落下中の球を左右に動かす
- **結果**:
  - 球が画面下の水平線にぶつかると上に跳ね返り、**球の直径が少し大きくなる**
  - 球が左右の線の中央の隙間を通り抜けると、画面が下方向にスクロールし、次の（より狭い）隙間が下から現れる
- **報酬**: 隙間を通り抜けるたびにスコア +1。最高スコア更新
- **継続動機**: 「あと1個通せそう」「自己ベストにあと少し」

### 終了条件
- 球が次の隙間の幅より大きくなり、物理的に通れなくなった瞬間にゲームオーバー
  - ❓ 「線にぶつかったが通れない」状態の判定方式：球の直径 > 隙間幅 になったら即ゲームオーバー？ それとも実際に当たって弾かれたら？

### 勝利条件
- なし（エンドレス、スコアアタック）

## 3. 画面遷移

```
[Title] ──tap "Start"──▶ [Game] ──ゲームオーバー──▶ [Result] ──tap──▶ [Title]
                            ▲                                            │
                            └────── tap "Retry" ──────────────────────────┘
```

- **Title**: タイトル、Startボタン、最高スコア表示、（任意）操作モード切替（傾き/スワイプ）
- **Game**: プレイ画面。HUDにスコアのみ表示
- **Result**: 今回のスコア、最高スコア、Retry / Titleへ戻る

## 4. 操作仕様

- **持ち方**: 片手
- **向き**: 縦固定
- **入力**:
  - **メイン**: 端末の傾き（DeviceOrientation / DeviceMotion API、加速度センサ）で球の横位置を制御。傾きの角度に応じて横方向の加速度を加える
  - **フォールバック**: 横スワイプ。**スワイプの速度・量に応じて球に横方向の運動量（impulse）を加え、空気抵抗で徐々に減衰**。フリック的に「弾く」操作感
- **iOS Safari対応**: DeviceMotionEvent は `requestPermission()` が必要 → タイトル画面でユーザーアクションをトリガーに許可を取る
- **想定解像度**: 縦長 9:16 基準（720×1280 → 任意解像度にスケール）

## 7. MVP スコープ

### Must（最初のプロトタイプに必須）
- ボールが上から落下し、下の水平線でバウンドする物理挙動
- バウンドごとにボール直径が増加
- 隙間を通り抜けると画面スクロール、新しい線が下から出現
- 次の隙間幅は徐々に狭くなる
- 横スワイプ操作（傾きより実装が安定するので先に）
- スコア表示（通せた回数）
- ゲームオーバー判定 / Result画面 / Retry
- localStorage で最高スコア保存

### Should（時間があれば）
- 加速度センサ操作
- 効果音（バウンド、通過、ゲームオーバー）
- アニメーション（通過時のキラッ、画面シェイク等の気持ちよさ）
- 操作モード切替UI

### Won't（今回はやらない）
- オンラインランキング
- 課金 / 広告
- 多言語化
- アカウント機能
- BGM（効果音のみ）

## バランス調整値（仮、`src/config/balance.ts` に集約予定）

| 項目 | 初期値（仮） | 備考 |
|---|---|---|
| 重力加速度 | 600 px/s²（地球の約1/16 換算） | 「ゆるやか」な落下感 |
| 反発係数 | 0.85 | 跳ね返りは少しずつ弱まる |
| 初期ボール直径 | 30 px | |
| バウンドごとの増加量 | +2 px | 線にバウンドするたびに増加 |
| 初期隙間幅 | ボール直径の 4倍（120 px） | |
| 隙間幅の減少率 | 通過ごとに -8 px（下限：ボール直径+10px） | プレイテストで調整 |
| 画面スクロール速度 | 600 px / 0.4秒（イージング付き） | |
| 横方向の空気抵抗 | 0.95（毎フレーム速度に乗算） | スワイプ後にだんだん止まる |
| スワイプ係数 | スワイプ速度 × 1.0 を横方向のimpulseに変換 | プレイテストで調整 |

### 物理の懸案（プレイテストで判断）
- 反発0.85だと、球が線上で完全に静止する可能性がある。対策案：
  - (A) 静止しかけたら自動で軽い上向き力（最低限の跳ね）を加える
  - (B) 静止状態でもプレイ続行可。プレイヤーが横に押し出して隙間に落とせばOK
  - (C) 一定時間静止したらゲームオーバー
  - **暫定**: (B) を採用。実装後、テストで違和感あれば見直し
