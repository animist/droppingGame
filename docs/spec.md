# Dropping — ゲーム仕様書

落ちてくる球を左右に操って、画面下の隙間に通し続ける、片手で遊べる無限スクロール型のカジュアルゲーム。

---

## 1. コンセプト

- **タイトル**: Dropping
- **ジャンル**: カジュアル / スキル系ミニゲーム
- **プラットフォーム**: スマートフォン Web（縦画面）
- **1行ピッチ**: 落ちてくる球を左右に操って画面下の隙間に通し続ける、片手で遊べる無限スクロール型のスキマ時間ゲーム
- **ターゲット**: 電車待ち・休憩時間など、1分前後の暇つぶしを求めるカジュアルプレイヤー

---

## 2. コアループ

1. 画面上から球が落下（重力で加速）
2. 画面下の左右にある2本の水平線（中央に隙間あり）にバウンドする
3. プレイヤーは傾き / スワイプで球の横位置を操作し、隙間を狙う
4. **球が線にバウンドするたびに直径が +2px 増加**
5. 隙間を通り抜けると画面がスクロールし、新しい隙間（前回より少し狭い）が下から登場
6. ボーナス: **バウンドなしで通過するとパーフェクト** (+3点) + 連続パーフェクトで音程上昇
7. 球が次の隙間より大きくなった瞬間にゲームオーバー

### 終了条件

球の直径 > 現在の隙間幅 になった瞬間にゲームオーバー（バウンドで成長した結果、あるいは新ステージ生成時に新隙間が球より小さい場合）。

### 勝利条件

なし（エンドレス、スコアアタック）

---

## 3. 画面遷移

```
[Boot] ─→ [Title] ─tap─▶ [Game] ─game over─▶ [Result] ─tap─▶ [Game]
                            ▲                                  │
                            └─────── retry ────────────────────┘
```

- **Boot**: 起動時の初期化（現在はアセットなしで即タイトルへ）
- **Title**: タイトルロゴ、最高スコア表示、TAP TO START、背景に浮遊するデモボール
- **Game**: メインプレイ画面。HUD はスコア数字のみ（中央上部、半透明）
- **Result**: GAME OVER、今回スコア（カウントアップ演出）、最高スコア、NEW BEST 演出、TAP TO RETRY

---

## 4. 操作仕様

- **持ち方**: 片手
- **向き**: 縦固定
- **入力**:
  - **メイン**: 端末の傾き（DeviceOrientationEvent の `gamma`）→ 球に横方向の加速度
  - **メイン**: 横スワイプ / ドラッグ → 球に横方向のインパルス
  - 両方常時有効（同時に効くが、実際にはどちらかしか使われない）
- **iOS Safari 対応**:
  - `DeviceOrientationEvent.requestPermission()` をタイトル画面のタップ起点で呼ぶ
  - WebAudio は 1サンプル無音バッファを同時に再生して完全アンロック
- **想定解像度**: 720×1280 (9:16) を仮想キャンバスとし `Phaser.Scale.FIT` で実機に合わせて縮小

---

## 5. ゲームメカニクスの詳細

### 5.1 ボール

- 円形、初期直径 30px、黄色 → 赤に直径に応じてグラデーション
- 重力 (px/s²) で落下、線への反発係数 0.85（少しずつエネルギー減衰）
- 壁（画面左右）への反発は 1.0（エネルギーロスなし）
- バウンドのたびに直径 +2px

### 5.2 隙間（ライン）

- 画面下に水平線2本、中央に隙間
- 隙間の中心位置は **生成のたびにランダム** 配置
- **±3px の伸縮**（左右独立、`sin` 波で連続的に振動）→ 物理ボディも追従するので当たり判定に反映
- 通過ごとに隙間幅が縮む（現在 -6px / 通過）
- 隙間幅の下限は `球の直径 + 10px`

### 5.3 パーフェクトとストリーク

- **PERFECT**: そのステージで線にバウンドせず隙間を通過 → スコア +3（通常 +1 + ボーナス +2）
- **連続PERFECT**: ストリーク管理。連続するごとに音程シフトが累積（FALL_STREAK_PITCH_CENTS = 150 cents / 連続）
- ストリークは **線にバウンドした瞬間にリセット**（壁バウンドではリセットしない）
- ストリーク中は「PERFECT!×N」表示と落下音の音程が上昇

### 5.4 危険警告

- 球の直径 / 隙間幅 が 0.85 を超えると、線が赤くアルファ点滅する
- ストリーク中も含めて、ゲーム終盤の緊張感を視覚で予告

### 5.5 ゲームオーバー

- 球の直径 > 隙間幅 になった瞬間にトリガー
- 大きなカメラシェイク、ゲームオーバー音、振動 → 700ms 後 Result へ遷移
- 物理ボディは即座に停止（残響を防ぐ）

## 6. 演出（実装済み）

### 6.1 視覚

- **スクワッシュ → 拡大 → 戻し** のチェーンアニメ（バウンドのたびに）
- **バウンス時パーティクル**: 上方向に飛び散る粒（ボール色を継承）
- **通過時フラッシュ**: 画面全体が一瞬白く明滅
- **通過時パーティクル**: 放射状に飛び散る粒（PERFECT は色が金、粒の数が増加）
- **通過時スコアポップ**: HUD のスコア文字が瞬時に拡大
- **"+1" / "+3" ポップアップ**: 通過位置から数字が浮き上がる
- **"PERFECT!" 中央テキスト**: 連続数表記付き
- **カメラシェイク**: バウンドはサイズに比例、ゲームオーバーは大きく
- **ボールトレイル**: 高速移動時に残像
- **ボール色変化**: 黄 → 赤（直径に応じて）
- **背景色変化**: 青紫 → 赤紫（スコアに応じて）
- **タイトル画面のデモボール**: 背景で斜めに浮遊

### 6.2 スクロール演出

- 古い線が上方向にイージング `Cubic.easeIn` で消える
- ボールがイージング `Cubic.easeOut` で元の高さに戻る
- 新しい線が画面下から `Back.easeOut` で弾むように登場

### 6.3 音（WebAudio で合成、ファイル不要）

- **バウンド音**: トライアングル波。ボール直径が大きくなるほど低音化
- **壁バウンド音**: 短い矩形波
- **通過音**: 3音上昇アルペジオ
- **PERFECT音**: 4音上昇アルペジオ（連続数で音程シフト）
- **ゲームオーバー音**: のこぎり波の下降スイープ
- **落下音**（風切り音、連続）:
  - 三角波 + バンドパスフィルタ（共振 Q=6）の合成
  - `|velocity.y|` で音量と音程を変調（落下中も上昇中も鳴る）
  - 上昇中はわずかにデチューンして上下を区別
  - PERFECT 連続数に応じて全体的に音程上昇（ステージを跨いで保持）

### 6.4 ハプティック

- バウンド: 短い振動
- 通過: パターン振動
- PERFECT: 長めパターン
- ゲームオーバー: 強パターン

### 6.5 Result 画面の演出

- フェードイン
- スコア数字を 0 からカウントアップ
- 新記録時は数字が金色になり 3回脈動
- 「NEW BEST!」がディレイ付きで Back.easeOut でポップイン
- 入力受付までは 400ms 待機。受付後はタップでアニメーションをスキップ可能

## 7. データモデル（localStorage）

| キー | 型 | 説明 |
|---|---|---|
| `dropping.highScore` | number | 最高スコア（通過回数とPERFECTボーナスの合算） |
| `dropping.playCount` | number | 累計プレイ回数 |

> プライベートモード等で localStorage が使えない環境では try/catch で握りつぶし、ゲームは正常動作する

---

## 8. 技術スタック

- **ビルド**: Vite 5
- **言語**: TypeScript 5（strict）
- **エンジン**: Phaser 3（Arcade Physics）
- **音**: WebAudio API 直接利用（外部音源ファイルなし、すべて合成）
- **入力**: Phaser Input + DeviceOrientationEvent + navigator.vibrate
- **永続化**: localStorage
- **ホスティング**: 開発時は Vite dev server + cloudflared quick tunnel で実機テスト

## 10. バランス調整値

すべて `src/config/balance.ts` に集約。各定数にコメントで「役割と単位、増減で何が起きるか」を付記してある。主な分類：

- キャンバス / 物理基礎
- ボール（初期サイズ・成長量）
- 隙間（初期幅、減少率、最小マージン、ノーバウンスボーナス）
- ライン伸縮（振幅・周期）
- 線（太さ・位置・色）
- 色（ボール・背景の段階変化）
- 操作（スワイプ・傾き・最大速度）
- スクロール演出（持続時間・登場オフセット）
- バウンド演出（スクワッシュ・パーティクル）
- 隙間通過演出（フラッシュ・パーティクル・スコアポップ）
- カメラシェイク
- スコアポップアップ
- ボールトレイル
- 危険警告
- 落下音（最大速度・最大音量・波形・周波数範囲・フィルタ・連続シフト）
- パーフェクト演出

## 12. 開発時の動作確認

```bash
# 依存インストール
npm install

# 開発サーバー起動（http://localhost:5173）
npm run dev

# 実機テスト用（インターネットから到達可能なURLを発行）
cloudflared tunnel --url http://localhost:5173

# 型チェック
npx tsc --noEmit

# プロダクションビルド
npm run build
```

`vite.config.ts` に `allowedHosts: ['.trycloudflare.com', 'localhost']` を設定済みで、cloudflared 経由の HTTPS アクセスを許可している（iOS Safari の加速度センサ許可ダイアログは HTTPS が必須）。
