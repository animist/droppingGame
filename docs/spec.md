# Dropping — ゲーム仕様書

落ちてくる球を左右に操って、画面下の隙間に通し続ける、片手で遊べる無限スクロール型のカジュアルゲーム。

---

## 1. コンセプト

- **タイトル**: Dropping
- **ジャンル**: カジュアル / スキル系ミニゲーム
- **プラットフォーム**: スマートフォン Web（縦画面）
- **1行ピッチ**: 落ちてくる球を左右に操って画面下の隙間に通し続ける、片手で遊べる無限スクロール型のスキマ時間ゲーム
- **ターゲット**: 電車待ち・休憩時間など、1分前後の暇つぶしを求めるカジュアルプレイヤー

---

## 2. コアループ

1. 画面上から球が落下（重力で加速）
2. 画面下の左右にある2本の水平線（中央に隙間あり）にバウンドする
3. プレイヤーは傾き / スワイプで球の横位置を操作し、隙間を狙う
4. **球が線にバウンドするたびに直径が +2px 増加**
5. 隙間を通り抜けると画面がスクロールし、新しい隙間（前回より少し狭い）が下から登場
6. 各種ボーナス（PERFECT / コンボ / 終端色 / ニアミス）でスコアが伸びる（→ 5.3〜5.5）
7. 球が次の隙間より大きくなった瞬間にゲームオーバー

### 終了条件

球の直径 > 現在の隙間幅 になった瞬間にゲームオーバー（バウンドで成長した結果、あるいは新ステージ生成時に新隙間が球より小さい場合）。

### 勝利条件

なし（エンドレス、スコアアタック）

---

## 3. 画面遷移

```
[Boot] ─→ [Title] ─tap─▶ [Game] ─game over─▶ [Result] ─tap─▶ [Game]（即リトライ）
              ▲                                                │
              └────────────── HOME ボタン ──────────────────────┘
```

- **Boot**: 起動時の初期化。Webフォント（M PLUS Rounded 1c）の読み込みを待ってから Title へ（上限1.5秒、超過時はフォールバックフォントで開始）
- **Title**: タイトルロゴ、最高スコア表示、TAP TO START、背景に浮遊するデモボール。タップで音声アンロック + 傾きセンサー許可 → Game へ
- **Game**: メインプレイ画面。HUD はスコア数字のみ（中央上部、半透明）。初回プレイ時のみ操作ガイドを表示
- **Result**: GAME OVER、今回スコア（カウントアップ演出）、最高スコア、NEW BEST 演出、プレイ内訳。**画面タップで即 Game 再開（即リトライ）**、下部の HOME ボタンで Title へ
- **SoundTest**: 効果音の比較試聴用シーン（GAME OVER 候補音 A〜E など）。**UI からの導線はなく**、開発時にコンソールから `game.scene.start('SoundTest')` 等で遷移する開発用シーン

## 4. 操作仕様

- **持ち方**: 片手
- **向き**: 縦固定
  - `screen.orientation.lock('portrait')` をベストエフォートで試行（iOS Safari 等は未対応）
  - 横向き時は CSS メディアクエリ（`landscape and max-height:600px`）で「縦向きでプレイしてください」オーバーレイを表示
  - 横向き中は全シーンをポーズ + AudioContext を一括サスペンド。縦に戻ると再開し `scale.refresh()` で描画領域を再計算
- **入力**:
  - **メイン**: 端末の傾き（DeviceOrientationEvent の `gamma`）→ 球に横方向の加速度
    - **キャリブレーション**: Game 開始 200ms 後の傾き値を「中立」として記録し、持ち方の癖を吸収（以後は中立値からの差分で操作）
    - デッドゾーン 5°（手ブレ対策）
  - **メイン**: 横スワイプ / ドラッグ → 球に横方向のインパルス
  - 両方常時有効（同時に効くが、実際にはどちらかしか使われない）
- **iOS Safari 対応**:
  - `DeviceOrientationEvent.requestPermission()` をタイトル画面のタップ起点で呼ぶ
  - WebAudio は 1サンプル無音バッファをタップ中に再生して完全アンロック
  - AudioContext がバックグラウンド等で suspended に戻った場合に備え、visibilitychange / ユーザー操作で自動 resume するフックを常設
- **想定解像度**: 720×1280 (9:16) を仮想キャンバスとし `Phaser.Scale.FIT` で実機に合わせて縮小。中央寄せは CSS（flex）側で行い、Phaser 側は `NO_CENTER`
- **初回オンボーディング**: 累計プレイ回数が 0 のときだけ、ゲーム内に「← スワイプ / かたむけ →」「たまを すきまに とおそう」のガイドを表示。最初の通過（またはゲームオーバー）でフェードアウト

## 5. ゲームメカニクスの詳細

### 5.1 ボール

- 円形、初期直径 30px
- 重力 (px/s²) で落下、線への反発係数 0.85（少しずつエネルギー減衰）
- 壁（画面左右）への反発は 1.0（エネルギーロスなし）
- バウンドのたびに直径 +2px
- **色は黄 → 赤のグラデーション。進行度は「ボール直径 / 現在の隙間幅」の比率**（直径そのものではなく、穴に対する余裕度）で決まる。比率 0.4 以下で黄、0.95 以上で赤
- **ベロシティストレッチ**: 移動速度に応じて進行方向に伸びる（速いほど細長く）。バウンド時のスクワッシュ中はそちらを優先

### 5.2 隙間（ライン）

- 画面下に水平線2本、中央に隙間
- 隙間の中心位置は **生成のたびにランダム** 配置
- **±3px の伸縮**（左右独立、`sin` 波で連続的に振動）→ 物理ボディも追従するので当たり判定に反映
- 通過ごとに隙間幅が縮む（現在 -6px / 通過）
- 隙間幅の下限は `球の直径 + 10px`
- **隙間端マーカー**: ラインの内側端（隙間の両端）に発光する点を配置し、端の視認性を上げる。伸縮・登場/退場アニメ・警告色にも追従

### 5.3 スコアリング

通過1回の得点は以下の合算:

| 要素 | 条件 | 加点 |
|---|---|---|
| 基本 | 隙間を通過 | +1 |
| PERFECT | そのステージで線にバウンドせず通過 | +2 |
| コンボ | PERFECT が2連続以上 | +連続数（streak=2 → +2、3 → +3 …） |
| 終端色ボーナス | ボール色の進行度 ≥ 0.75（ほぼ赤）で通過 | +10（PERFECT 時は +20） |
| ニアミス（CLOSE） | ボール端〜ライン端の余白 ≤ 14px で通過 | +2 |

- **連続PERFECT（音で立体的に高揚）**: 連続するごとに、①落下音の音程が上昇、②PERFECT音が音階（ドレミ）を1段ずつ上昇（1オクターブ登り切ると次のオクターブへ。上限+2オクターブ）、③低〜中音の持続コードが1声ずつ積み上がり周回ごとに音量を増す（→ 7.3）
- ストリークは **線にバウンドした瞬間にリセット**（壁バウンドではリセットしない）
  - リセット時、積層コードは **ピッチを落としながら崩落**。一定連続数以上（`STREAK_LOST_MIN`）を失った場合は **脱色フラッシュ + 「STREAK LOST」テキスト + 専用SFX + 振動** の喪失演出が出る（チェーンを「育てて失うと痛い資産」にする）
- ストリーク中は「PERFECT!×N」表示

### 5.4 ニアミス（CLOSE）演出

- 余白 14px 以下のギリギリ通過で発動
- **ストップモーション**: 物理・tween を一時停止し、ボール位置をピボットに固定したままカメラが 2.2倍ズームイン（200ms）→ 保持（160ms）→ ズームアウト（280ms）
- 「CLOSE! +2」テキスト、専用 SFX（上向きスイープ）、振動
- ニアミス時は通常のタイムダイレーション（5.6）はスキップ

### 5.5 マイルストーン

- スコアが **10 / 25 / 50 / 100 / 200 / 500** に到達すると発動（1回の通過で複数跨いだ場合は最高位のみ）
- 画面全体の金色フラッシュ + 到達値の大型テキスト + 「MILESTONE」表示 + ファンファーレ SFX + 振動

### 5.6 ベスト超え（プレイ中）

- プレイ中にスコアが **自己ベストを上回った瞬間** に1回だけ発動（初回プレイ＝ベスト0のときは発動せず、Result の NEW BEST に任せる）
- スコアHUD下に「NEW BEST!」がポップイン + 祝福チャイム SFX + 振動
- 以後そのプレイ中はスコアHUDが金色のままになる

### 5.7 タイムダイレーション

- 通過の瞬間にゲーム速度を 35% に落とし、実時間 90ms 保持 → 160ms かけて復帰（成功の瞬間を強調するスローモーション）
- ニアミス時は専用演出があるためスキップ

### 5.8 危険警告

- 球の直径 / 隙間幅 が 0.85 を超えると、線と隙間端マーカーが赤くアルファ点滅する
- 同時に **画面周辺の赤ビネットが脈動** し、**BGM にローパスがかかってこもる**（緊張感を視覚+聴覚で予告）
- 警告解除（通過 or ゲームオーバー）でビネット・BGM とも元に戻る

### 5.9 ゲームオーバー（死の演出）

- 球の直径 > 隙間幅 になった瞬間にトリガー
- 演出シーケンス:
  1. **ボールが破裂** してボール色の破片が放射状に飛び散る
  2. **BGM がテープストップ**（鳴っている全ノートのピッチが2オクターブ落ちながら停止）
  3. 暗幕オーバーレイで **背景の彩度が抜ける**
  4. 隙間の位置に **ボール直径の赤いゴースト円 + 「BALL N > GAP M」** を重ね、なぜ死んだかを可視化（サイズ起因の死のみ）
  5. 一瞬のスローモーション（tween のみ減速、実時間で復帰）
  6. カメラシェイク + ゲームオーバー音 + 振動 → 1500ms 後 Result へ遷移
- 物理ボディは即座に停止。タイムダイレーション / ニアミスズームが残っていても強制復帰
- ハイスコア / プレイ回数を localStorage に保存

## 6. 品質ティア（端末性能対応）

`src/config/quality.ts` で起動前に端末性能を静的推定し、演出の重さを切り替える。

| 項目 | high | low |
|---|---|---|
| グロー (postFX) | ON | OFF（最大のボトルネックのため完全無効） |
| トレイル生成間隔 | 30ms | 60ms（間引き） |
| パーティクル数 | ×1.0 | ×0.5 |

- 推定材料: `devicePixelRatio`（高密度ほど減点）、`deviceMemory`、`hardwareConcurrency` のスコアリング
- 将来拡張の想定: FPS 実測によるタイトル中の補正 → 手動トグル（いずれも未実装）
- ※ Scale.FIT + 720×1280 固定のため内部描画解像度は DPR に依存せず、DPR キャップは不要

## 7. 演出（実装済み）

### 7.1 視覚

- **共通フォント**: 全シーンのテキストに丸ゴシックWebフォント「M PLUS Rounded 1c」（`src/config/ui.ts` の `FONT_FAMILY`）。index.html で読み込み、Boot で待機
- **背景シェード**: 縦グラデーション + 四隅ビネットの共通テクスチャ（`src/util/bgShade.ts`、低解像度Canvasで1回生成して全シーンで共用）。Game ではパララックスの手前に敷いて奥行きを出す。Title / Result にも適用
- **ボールのハイライト**: 左上に白い小円を重ねて球体感を出す。位置・大きさはスクワッシュ／ストレッチの変形にも毎フレーム追従
- **ベロシティストレッチ**: 速度に応じてボールが進行方向に伸びる（→ 5.1）
- **隙間端マーカー**: 隙間の両端の発光点（→ 5.2）。ライングローと同期して呼吸する
- **スクワッシュ → 拡大 → 戻し** のチェーンアニメ（バウンドのたびに）
- **バウンス時パーティクル**: 上方向に飛び散る粒（ボール色を継承）
- **通過時フラッシュ**: 画面全体が一瞬白く明滅
- **通過時パーティクル**: 放射状に飛び散る粒（PERFECT は粒の数が増加）
- **通過時スコアポップ**: HUD のスコア文字が瞬時に拡大
- **得点ポップアップ**: 通過位置から「+N」が浮き上がる。通常=黄 / PERFECT=金 / 終端色=赤 / 終端色+PERFECT=ピンク と格付けで色・サイズが変わる
- **"PERFECT!" 中央テキスト**: 連続数表記付き
- **カメラシェイク**: バウンドはサイズに比例、ゲームオーバーは大きく
- **ボールトレイル**: 高速移動時に残像（品質ティアで間隔が変わる）
- **常時パーティクル**: 移動中、ボールの縁からきらめく粒を継続的に散らす。**PERFECTコンボ1につき粒が+1個**（上限6）、コンボ中は金色の粒が混ざる
- **ボール色変化**: 黄 → 赤（直径/隙間幅の比率に応じて）
- **背景色変化**: 青紫 → 赤紫。「隙間幅 / ボール直径」の比率を4段階の区分線形で補間（スコアではなく難易度ベース）
- **バイオーム（背景パレット）**: shaderモード時、スコア帯（0/25/75/150/300）で背景の基調色/終端色（`zoneCool`/`zoneHot`）が変わり、ゾーン切替のたびに約1.5秒かけて滑らかに遷移（宙→深海→樹海→黄昏→深淵）。エンドレスに旅情と前進感を与える。危険時の赤シフト（`progress`）はゾーンに依らず機能する
- **グロー（発光）**: ボールとラインに postFX グロー。`sin` で強度が揺らぐ「呼吸する発光」。ボールは終端色に近づくほど強くなる（high ティアのみ）。**ボールは拡散距離を大きくして柔らかくぼかし**、ラインはシャープのまま（`GLOW_BALL_DISTANCE` / `GLOW_DISTANCE` で個別調整）
- **背景パララックス**: 遠・中・近の3層ドット群。常時ゆるやかに上方向へドリフトし、ステージスクロール時はラインと同じイージングで層ごとの視差付きスクロール
- **タイトル画面のデモボール**: 背景で斜めに浮遊

### 7.2 スクロール演出

- 古い線が上方向にイージング `Cubic.easeIn` で消える
- ボールがイージング `Cubic.easeOut` で元の高さに戻る
- 新しい線が画面下から `Back.easeOut` で弾むように登場
- パララックス背景もラインと同じ時間・イージングで連動スクロール

### 7.3 効果音（WebAudio で合成、ファイル不要）

- **バウンド音**: トライアングル波。ボール直径が大きくなるほど低音化。1回ごとに音程±120cents・音量±40%のゆらぎで個性を出す
- **壁バウンド音**: 短い矩形波（音程ゆらぎ付き）
- **通過音**: 3音上昇アルペジオ
- **PERFECT音（ドレミ階段）**: 連続数に応じて音階（Cメジャー＝Aナチュラルマイナー）を1段ずつ上昇。1オクターブ登り切ると次のオクターブへ繰り返し（上限+2オクターブ）、線バウンドで途切れると最下段へ戻る。BGM(Am→F)と同じ音集合で在key
- **積層コード（PERFECTチェーン）**: PERFECTごとに低〜中音（Aマイナーペンタ）の持続音を1声ずつ積み、和音が育つ。音程は上げず、周回（8声で1周）ごとに音量だけを加算してスウェル。ストリーク途切れ／ゲームオーバーでピッチを落としつつ崩落する
- **ニアミス音**: のこぎり波の鋭い上向きスイープ + 高音
- **マイルストーン音**: メジャーアルペジオの上昇ファンファーレ
- **ゲームオーバー音**: のこぎり波の下降グリッサンドを 180ms 間隔で3回重ねる
- **リザルト画面メロディ**: 8bit風クロマチック下降 (A) → 休符 → マイナーアルペジオ (B)
- **落下音**（風切り音、連続）:
  - 三角波 + バンドパスフィルタ（共振 Q=6）の合成
  - `|velocity.y|` で音量と音程を変調（落下中も上昇中も鳴る）
  - 上昇中はわずかにデチューンして上下を区別
  - PERFECT 連続数に応じて全体的に音程上昇（ステージを跨いで保持）
- **ベスト超え音**: 自己ベスト更新の瞬間の短い祝福チャイム（C6→G6→C7）
- **ステレオパン**: ボールの x 位置に応じてバウンド/通過系の音が左右に定位（強さ 0.85）
- **ディレイのセンドバス**: ワンショット効果音だけを薄くフィードバックディレイ（0.16s、ローパス付き）へ送り、合成音に空間的なまとまりを与える。落下音（連続）と BGM はにごるためドライのまま
- SoundTest シーンで GAME OVER 候補音 A〜E と現行音を比較試聴できる

### 7.4 BGM（プロシージャル、ファイル不要）

`src/audio/music.ts`。ルックアヘッド方式のステップシーケンサ（16ステップ、104 BPM）で Am→F のループを合成。

- **スコア連動のレイヤー追加（intensity 0〜3）**:
  - 常時: ベース（三角波）
  - スコア 6 以上: アルペジオ（サイン波）
  - スコア 16 以上: ハイハット（ハイパスノイズ）
  - スコア 32 以上: 1オクターブ上の上声
- Game 開始でフェードイン、シーン終了でフェードアウト
- **ゲームオーバー時はテープストップ**: 鳴っている全ノートのピッチを2オクターブ落としながら停止
- **危険警告中はローパスでこもる**（`MUSIC_MUFFLE_HZ`）。警告解除で全開に戻る
- SFX とは独立した音量バス（`MUSIC_VOLUME`）+ 常設ローパスフィルタを持つ

### 7.5 ハプティック

- バウンド: 短い振動（サイズに比例）
- 通過: パターン振動
- PERFECT / ニアミス / マイルストーン: 専用パターン
- ゲームオーバー: 強パターン

### 7.6 Result 画面の演出

- フェードイン + リザルトメロディ
- スコア数字を 0 からカウントアップ
- 新記録時は数字が金色になり 3回脈動
- 「NEW BEST!」がディレイ付きで Back.easeOut でポップイン
- **プレイ内訳**: カウントアップ完了後に「PERFECT ×N / COMBO ×N / CLOSE ×N」を1行でフェードイン表示（実績のあった項目のみ。COMBO は最大連続2以上のときだけ）
- 入力受付までは 400ms 待機。受付後 1タップ目でカウントアップをスキップ
- **画面タップで即 Game 再開（即リトライ）**。下部の HOME ボタンで Title へ戻る（音声・傾きセンサーは初回 Title で許可済みのため直接 Game 開始で問題ない）

## 9. 技術スタック

- **ビルド**: Vite 5（`base: './'` で相対パスビルド → サブパス配下でも動作）
- **言語**: TypeScript 5（strict）
- **エンジン**: Phaser 3（Arcade Physics）
- **音**: WebAudio API 直接利用（外部音源ファイルなし、SFX・BGM ともすべて合成。ワンショットSFXはディレイのセンドバス付き）
- **フォント**: Google Fonts「M PLUS Rounded 1c」（400/700/800）。Boot で読み込み待機、未到達時は丸ゴ系フォールバック
- **入力**: Phaser Input + DeviceOrientationEvent + navigator.vibrate
- **永続化**: localStorage
- **PWA**: `manifest.webmanifest` + ホーム画面追加用メタタグ（standalone 表示）
- **ホスティング**: 開発時は Vite dev server + cloudflared quick tunnel で実機テスト

## 11. バランス調整値

すべて `src/config/balance.ts` に集約。各定数にコメントで「役割と単位、増減で何が起きるか」を付記してある。主な分類：

- キャンバス / 物理基礎
- ボール（初期サイズ・成長量）
- 隙間（初期幅、減少率、最小マージン、ノーバウンスボーナス、終端色ボーナス）
- ライン伸縮（振幅・周期）
- 線（太さ・位置・色）
- 色（ボール・背景の段階変化の比率しきい値）
- 操作（スワイプ・傾き・最大速度）
- スクロール演出（持続時間・登場オフセット）
- バウンド演出（スクワッシュ・パーティクル）
- 隙間通過演出（フラッシュ・パーティクル・スコアポップ）
- カメラシェイク
- スコアポップアップ
- ボールトレイル
- 常時パーティクル（間隔・サイズ・漂い・コンボ追加数・金色比率）
- 危険警告
- 落下音（最大速度・最大音量・波形・周波数範囲・フィルタ・連続シフト）
- パーフェクト演出
- ニアミス演出（判定余白・ボーナス・ズーム）
- マイルストーン（しきい値リスト・表示時間）
- タイムダイレーション
- 隙間端マーカー（半径・色）
- ベロシティストレッチ（速度域・最大伸び率）
- 危険警告の追加演出（赤ビネット濃度・BGMローパス周波数）
- 死亡演出（破裂パーティクル・スロー・暗幕・Result遷移待ち）
- グロー（基準強度・揺らぎ）
- ステレオパン / 効果音ゆらぎ / ディレイセンド（タイム・フィードバック・トーン・量）
- BGM（テンポ・音量・intensity しきい値）
- 背景パララックス（ドリフト速度・各層の点数）
- バイオーム（スコア帯ごとのパレット `BIOMES`・遷移時間）
- ストリーク喪失演出（発動の最小連続数・脱色フラッシュの濃さ/時間）

## 13. 開発時の動作確認

```bash
# 依存インストール
npm install

# 開発サーバー起動（http://localhost:5173）
npm run dev

# 実機テスト用（インターネットから到達可能なURLを発行）
cloudflared tunnel --url http://localhost:5173

# 型チェック
npx tsc --noEmit

# プロダクションビルド（型チェック込み）
npm run build
```

`vite.config.ts` に `allowedHosts: ['.trycloudflare.com', 'localhost']` を設定済みで、cloudflared 経由の HTTPS アクセスを許可している（iOS Safari の加速度センサ許可ダイアログは HTTPS が必須）。
